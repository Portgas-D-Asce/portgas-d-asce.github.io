GMRES 方法详解

GMRES（Generalized Minimal RESidual，广义最小残差法） 是求解大型非对称线性方程组 \(Ax=b\) 最主流的 Krylov 子空间迭代方法之一。它的核心思想非常明确：在第 \(m\) 步迭代时，于仿射空间 \(x_0 + \mathcal{K}_m(A, r_0)\) 中寻找使残差 2-范数最小的近似解。

与共轭梯度法（CG）要求矩阵对称正定不同，GMRES 对系数矩阵 \(A\) 没有对称性要求，只要求其非奇异，因此适用范围远广于 CG。

一、核心思想：在 Krylov 子空间中最小化残差

1.1 Krylov 子空间

给定初始猜测 \(x_0\)，初始残差 \(r_0 = b - Ax_0\)。第 \(m\) 步的 Krylov 子空间定义为

\[\mathcal{K}_m(A, r_0) = \operatorname{span}\{r_0, Ar_0, A^2r_0, \dots, A^{m-1}r_0\}.\]

GMRES 寻找的近似解具有形式

\[x_m = x_0 + V_m y_m,\]

其中 \(V_m = [v_1, \dots, v_m]\) 是 \(\mathcal{K}_m\) 的一组标准正交基，\(y_m \in \mathbb{R}^m\) 待定。

1.2 最小残差条件

GMRES 要求 \(x_m\) 满足

\[\|b - Ax_m\|_2 = \min_{x \in x_0 + \mathcal{K}_m} \|b - Ax\|_2.\]

即 \(x_m\) 是 Krylov 子空间内使残差范数最小的解。

二、Arnoldi 过程：构造标准正交基

2.1 Arnoldi 关系

为了在 \(\mathcal{K}_m\) 中稳定地计算，GMRES 使用 Arnoldi 过程生成标准正交基 \(V_m\)。设 \(v_1 = r_0 / \|r_0\|_2\)，Arnoldi 迭代产生

\[AV_m = V_{m+1} \bar{H}_m,\]

其中 \(\bar{H}_m \in \mathbb{R}^{(m+1)\times m}\) 是上 Hessenberg 矩阵，\(V_{m+1} = [V_m, v_{m+1}]\) 的列向量标准正交。

2.2 递推公式

对 \(j=1,\dots,m\)：

\[w = Av_j,\] \[h_{ij} = v_i^{\mathsf T} w, \quad i=1,\dots,j,\] \[w = w - \sum_{i=1}^{j} h_{ij} v_i,\] \[h_{j+1,j} = \|w\|_2, \qquad v_{j+1} = w / h_{j+1,j}.\]

数值稳定性注意：经典 Gram–Schmidt 不稳定，实际实现使用修正 Gram–Schmidt（MGS） 或带重正交化的版本。MGS-GMRES 被证明是后向稳定的，且不会发生“幸运中断”以外的崩溃。

三、最小二乘问题的转化

3.1 关键等式

由 \(x_m = x_0 + V_m y_m\) 和 \(AV_m = V_{m+1}\bar{H}_m\)：

\[b - Ax_m = b - A(x_0 + V_m y_m) = r_0 - AV_m y_m.\]

因 \(r_0 = \beta v_1\)（\(\beta = \|r_0\|_2\)），且 \(V_{m+1}\) 的列标准正交，

\[\|b - Ax_m\|_2 = \|\beta e_1 - \bar{H}_m y_m\|_2,\]

其中 \(e_1 = (1,0,\dots,0)^{\mathsf T} \in \mathbb{R}^{m+1}\)。

3.2 小规模最小二乘

原 \(n\) 维问题转化为 \((m+1)\times m\) 的小规模最小二乘问题：

\[y_m = \arg\min_{y \in \mathbb{R}^m} \|\beta e_1 - \bar{H}_m y\|_2.\]

由于 \(\bar{H}_m\) 是上 Hessenberg 矩阵，可用 Givens 旋转逐步将其化为上三角形式，同时递推得到残差范数，无需显式求解最小二乘。

四、算法流程

算法（MGS-GMRES）

  1. 给定 \(x_0\)，计算 \(r_0 = b - Ax_0\)，\(\beta = \|r_0\|_2\)，\(v_1 = r_0/\beta\)。
  2. 对 \(j=1,2,\dots,m\)：
    • \(w = Av_j\)；
    • 对 \(i=1,\dots,j\)：\(h_{ij} = v_i^{\mathsf T} w\)，\(w = w - h_{ij} v_i\)；
    • \(h_{j+1,j} = \|w\|_2\)；
    • 若 \(h_{j+1,j} = 0\)，停止（Krylov 子空间已精确包含解）；
    • \(v_{j+1} = w / h_{j+1,j}\)；
    • 对 Hessenberg 矩阵应用 Givens 旋转，更新残差估计。
  3. 若残差满足容差，求解上三角系统得到 \(y_m\)，计算 \(x_m = x_0 + V_m y_m\)，停止。
  4. 否则令 \(m \leftarrow m+1\)，继续。

五、收敛性与终止性质

5.1 有限终止

在精确算术下，GMRES 至多 \(n\) 步得到精确解（因 Krylov 子空间维数不超过 \(n\)）。且残差范数单调不增：

\[\|r_{m+1}\|_2 \le \|r_m\|_2.\]

这是 GMRES 相对于其他 Krylov 方法（如 FOM）的核心优势：每一步都保证残差不增加。

5.2 收敛速度与谱的关系

若 \(A\) 可对角化 \(A = V\Lambda V^{-1}\)，则

\[\frac{\|r_m\|_2}{\|r_0\|_2} \le \kappa(V) \min_{p \in \mathcal{P}_m, p(0)=1} \max_{\lambda \in \Lambda(A)} |p(\lambda)|,\]

其中 \(\mathcal{P}_m\) 为次数不超过 \(m\) 的多项式集合。收敛速度取决于特征值的分布和特征向量的条件数。若特征值聚集在远离原点的区域，GMRES 收敛快。

5.3 与 FOM 的对比

FOM（Full Orthogonalization Method） 使用 Galerkin 条件 \(r_m \perp \mathcal{K}_m\)，而非最小残差。FOM 可能发生崩溃（当 Hessenberg 矩阵奇异时），且残差不一定单调下降。GMRES 的最小残差性质使其更鲁棒。

六、重启策略：GMRES(m)

6.1 问题：长递推

GMRES 的 Arnoldi 过程需要存储所有基向量 \(v_1,\dots,v_m\)，存储量 \(O(mn)\)；正交化计算量 \(O(m^2n)\)，随 \(m\) 线性增长。对于大规模问题，\(m\) 不能太大。

6.2 重启 GMRES(m)

每 \(m\) 步重启一次：以当前 \(x_m\) 作为新的 \(x_0\)，清空 Krylov 子空间，重新开始。存储量降为 \(O(mn)\)，每步计算量降为 \(O(mn)\)。

代价：重启破坏了全局最小残差性质，收敛可能变慢甚至停滞。实际中 \(m\) 常取 10–40。

七、预处理

预处理是 GMRES 实用化的关键。求解预处理系统

\[M^{-1}Ax = M^{-1}b\]

（左预处理）或等价形式（右预处理），使预处理后矩阵的特征值聚集，加速收敛。

常用预处理器：不完全 LU 分解（ILU）、稀疏近似逆（SPAI）、代数多重网格（AMG）、多项式预处理等。左预处理改变残差范数的度量，右预处理保持原残差，监控收敛时需注意区别。

八、优缺点总结

维度 GMRES
适用矩阵 任意非奇异方阵（非对称亦可）
核心性质 每步残差 2-范数全局最小
存储 \(O(mn)\)（重启后）
每步计算 一次矩阵-向量乘法 + \(O(mn)\) 正交化
收敛 依赖谱分布；重启可能停滞
与 CG 的关系 CG 是 GMRES 在对称正定情形下的短递推特例

结论：GMRES 是求解非对称线性系统最通用的 Krylov 方法，其最小残差性质保证了稳健的收敛行为。实际使用中必须结合重启（控制存储和计算量）与预处理（加速收敛），方能应对大规模科学与工程计算中的挑战。
