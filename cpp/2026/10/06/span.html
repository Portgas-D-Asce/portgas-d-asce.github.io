std::span 是 C++20 引入的非拥有连续视图，定义在 <span> 里。它是对一段连续内存的“窗口”，不持有数据、不管理生命周期，只提供访问接口。

是什么

std::span<T, Extent> 是对 [T*, T* + size) 这段连续内存的类型安全封装。

一句话： span 是“指针 + 长度”的安全替代品，是连续内存的通用视图。

它相当于：但带有完整容器接口、类型安全和编译期长度支持。

template <typename T>
struct span {
    T* data;
    std::size_t size;
};

标准定义

template <typename T, std::size_t Extent = std::dynamic_extent>
class span {
public:
    // 类型
    using element_type = T;
    using value_type = std::remove_cv_t<T>;
    using size_type = std::size_t;
    using difference_type = std::ptrdiff_t;
    using pointer = T*;
    using const_pointer = const T*;
    using reference = T&;
    using const_reference = const T&;
    using iterator = /* 实现定义 */;
    using reverse_iterator = std::reverse_iterator<iterator>;

    static constexpr std::size_t extent = Extent;

    // 构造
    constexpr span() noexcept;
    constexpr span(pointer ptr, size_type count);
    constexpr span(pointer first, pointer last);
    template <std::size_t N>
    constexpr span(element_type (&arr)[N]) noexcept;
    template <typename Container>
    constexpr span(Container& c);
    template <typename Container>
    constexpr span(const Container& c);

    // 访问
    constexpr reference operator[](size_type idx) const;
    constexpr reference front() const;
    constexpr reference back() const;
    constexpr pointer data() const noexcept;

    // 迭代
    constexpr iterator begin() const noexcept;
    constexpr iterator end() const noexcept;
    constexpr reverse_iterator rbegin() const noexcept;
    constexpr reverse_iterator rend() const noexcept;

    // 大小
    constexpr size_type size() const noexcept;
    constexpr size_type size_bytes() const noexcept;
    [[nodiscard]] constexpr bool empty() const noexcept;

    // 子视图
    constexpr span first(size_type count) const;
    constexpr span last(size_type count) const;
    constexpr span subspan(size_type offset,
                           size_type count = std::dynamic_extent) const;
};

关键：

部分 含义
T 元素类型
Extent 编译期长度，默认 std::dynamic_extent（运行期）

核心特点

特点 说明
非拥有 不持有数据，不分配/释放
连续 只能指向连续内存
轻量 通常是指针 + 长度
不检查越界 operator[] 不做边界检查
可写 span<T> 可写，span<const T> 只读
支持静态长度 span<T, N> 长度编译期已知
可拷贝 拷贝只是复制指针和长度

基本用法

从数组构造时，Extent 自动推导为 5：

int arr[5] = {1, 2, 3, 4, 5};
std::span<int> s(arr);       // 长度 5

std::cout << s.size();        // 5
std::cout << s[0];            // 1

std::span<int> s(arr);              // span<int, 5>
std::span<int, 5> t(arr);           // OK
std::span<int, 3> u(arr);           // 编译错误，长度不匹配

std::vector 构造

std::vector<int> v = {1, 2, 3};
std::span<int> s(v);          // 动态长度

从 std::array 构造

std::array<int, 4> a = {1, 2, 3, 4};
std::span<int> s(a);          // span<int, 4>

从指针 + 长度构造

int arr[5] = {1, 2, 3, 4, 5};
std::span<int> s(arr + 1, 3);   // 指向 arr[1..3]

从指针范围构造

std::span<int> s(arr, arr + 5);

静态长度

std::array<int, 4> a;
std::span<int, 4> s(a);   // 长度编译期已知
static_assert(s.extent == 4);

span 的成员函数

大小

s.size();          // 元素个数
s.size_bytes();    // 字节数 = size() * sizeof(T)
s.empty();         // size() == 0
s.extent;          // 编译期长度（可能是 dynamic_extent）

访问

s[0];              // 不检查越界
s.front();         // 第一个元素
s.back();          // 最后一个元素
s.data();          // 底层指针

迭代

for (auto x : s) { ... }
for (auto it = s.begin(); it != s.end(); ++it) { ... }

子视图

s.first(2);              // 前 2 个
s.last(2);               // 后 2 个
s.subspan(1, 2);         // 从索引 1 开始，长度 2
s.subspan(1);            // 从索引 1 到末尾

子视图返回的 span 仍然是视图，不拷贝数据。

为什么需要 span

问题：函数传数组/容器，接口不统一，每种容器一个重载，或者退化成指针 + 长度。

void f1(int* arr, std::size_t n);           // C 风格
void f2(const std::vector<int>& v);         // 只接受 vector
void f3(const std::array<int, 5>& a);       // 只接受固定大小 array
void f4(const std::initializer_list<int>&); // 只接受初始化列表

span 的解法：一个接口，接受所有连续内存容器。

void f(std::span<int> s) {
    for (int x : s) { /* ... */ }
}

int arr[5];
std::vector<int> v;
std::array<int, 4> a;
std::initializer_list<int> il;

f(arr);   // OK
f(v);     // OK
f(a);     // OK
f(il);    // OK

span 和 C++ 其他视图的对比

工具 拥有数据 连续 元素类型 引入
std::span<T> ❌ ✅ 任意 C++20
std::string_view ❌ ✅ char C++17
std::vector<T> ✅ ✅ 任意 C++98
std::array<T, N> ✅ ✅ 任意 C++11
std::initializer_list<T> ❌ ✅ 只读 C++11
std::ranges::view ❌ ❌ 任意 C++20

span 是“连续内存的通用视图”，string_view 是“字符的连续视图”。

span 和 string_view 的类比

  std::string_view std::span<T>
头文件 <string_view> <span>
元素 char 任意 T
引入 C++17 C++20
是否可写 否 是（span<T>）
用途 字符串视图 通用连续视图

span 是 string_view 的泛化版本。

生命周期陷阱

span 不拥有数据，必须保证底层数据比 span 活得久。

危险 1：返回局部数组的 span

std::span<int> f() {
    int arr[5] = {1, 2, 3, 4, 5};
    return arr;   // 悬空！arr 在函数返回后销毁
}

危险 2：vector 重新分配

std::vector<int> v = {1, 2, 3};
std::span<int> s(v);
v.push_back(4);   // 可能重新分配，s 悬空

危险 3：临时对象

std::span<int> s = std::vector<int>{1, 2, 3};   // 编译错误或悬空

标准库禁止从临时 vector 构造 span（有 delete 的重载）。

危险 4：string 的 c_str

std::span<const char> s = std::string("hello");   // 错误

从临时 string 构造 span 被禁止。

span 的静态长度优化

span<T, N> 的长度在编译期已知，可以：

  1. 避免存储长度。
  2. 编译期检查越界。
  3. 生成更优代码。
template <std::size_t N>
void process(std::span<int, N> s) {
    static_assert(N > 0);
    // s 的长度编译期已知
}

int arr[5];
process(std::span<int, 5>(arr));   // OK
process(std::span<int, 3>(arr));   // 编译错误

span<T, std::dynamic_extent> 的长度在运行期已知，等价于普通 span。

span 不能做什么

不能做 原因
拥有数据 非拥有视图
动态扩容 固定视图
插入/删除元素 不管理内存
指向非连续内存 只支持连续
检查越界 operator[] 不检查
延长生命周期 不持有数据

span 的替代方案

方案 优点 缺点
T* + size_t 简单 不安全，不统一
std::vector<T> 拥有数据 拷贝开销
std::string_view 字符串专用 只支持 char
std::span<T> 通用、零开销、安全 C++20 才有
std::ranges::subrange 支持任意迭代器 不要求连续

span 的实现细节

典型布局

template <typename T, std::size_t Extent>
class span {
    T* data_;
    // Extent == dynamic_extent 时，还有 size_
    std::conditional_t<Extent == dynamic_extent, std::size_t, empty> size_;
};

对静态 span<T, N>，不存 size_，因为 N 编译期已知。

大小

sizeof(std::span<int>);          // 通常是 16（指针 + size_t）
sizeof(std::span<int, 5>);       // 通常是 8（只有指针）

构造检查

对静态 span<T, N>，从数组构造时检查长度：

template <std::size_t M>
constexpr span(element_type (&arr)[M]) noexcept
    requires (Extent == std::dynamic_extent || Extent == M);

如果 M != Extent，编译错误。

常见陷阱

生命周期

std::span<int> make_span() {
    std::vector<int> v = {1, 2, 3};
    return v;   // 悬空
}

临时对象

std::span<const int> s = std::vector<int>{1, 2, 3};   // 编译错误

越界

std::span<int> s(arr, 5);
s[10];   // 未定义行为，不检查

const 传播

const std::span<int> s = arr;
s[0] = 42;   // OK，s 是 const 的 span，但元素可写

span 的 const 性和元素的 const 性分离

一句话总结

std::span<T, Extent> 是 C++20 的非拥有连续视图，是“指针 + 长度”的安全封装。它不持有数据，只提供访问接口，能统一接受数组、vector、array 等连续容器。支持编译期长度 span<T, N> 和运行期长度 span<T>。在 la 项目里，matrix::data() 返回 span，让静态矩阵和动态矩阵的底层数据访问接口统一。
