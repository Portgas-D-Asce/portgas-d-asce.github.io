std::any 是 C++17 引入的类型擦除容器，定义在 <any> 里。它能保存任意类型的单个值，并在运行期安全地取回。它是 void* 的类型安全替代品。

是什么

std::any 是一个可以装任意类型值的容器，且知道当前装的是什么类型。

一句话：any 是“任意类型”的容器：同一时刻装一个值，类型在运行期确定。

std::any a = 42;              // 装 int
a = 3.14;                     // 装 double
a = std::string("hello");     // 装 std::string

为什么需要 any

问题：需要保存“未知类型”的值

有些场景你事先不知道类型：

  • 配置系统：值可能是 int、double、string、bool。
  • 脚本引擎：变量类型在运行期确定。
  • 消息传递：消息负载类型多种多样。
  • 插件系统：参数类型由插件决定。

void* 的缺陷

void* p = new int(42);
// 取回时不知道类型，需要手动记录
// 没有类型安全，没有生命周期管理

void* 的问题：

  • 不知道类型，需要额外存标签。
  • 不安全，转错类型是未定义行为。
  • 不管理生命周期，需要手动 delete。

any 的解法

any 自动管理：

  • 当前类型（通过 typeid）。
  • 值的生命周期（构造/析构）。
  • 类型安全访问（any_cast 检查类型）。
std::any a = 42;
a = std::string("hello");

if (a.type() == typeid(std::string)) {
    std::cout << std::any_cast<std::string>(a);
}

基本用法

定义与赋值

std::any a;                    // 空
a = 42;                        // 装 int
a = 3.14;                      // 装 double
a = std::string("hello");      // 装 std::string
a = std::vector<int>{1,2,3};   // 装 vector

检查是否有值

std::any a;
a.has_value();   // false
a = 42;
a.has_value();   // true

清空

a.reset();       // 清空
a = {};          // 等价

访问：std::any_cast

std::any a = 42;

// 按值取
int x = std::any_cast<int>(a);

// 按引用取
int& r = std::any_cast<int&>(a);
r = 100;

// 按指针取
int* p = std::any_cast<int>(&a);
if (p) { std::cout << *p; }

类型不匹配时：

  • any_cast<T>(a)：抛 std::bad_any_cast。
  • any_cast<T>(&a)：返回 nullptr。

检查类型

std::any a = 42;
a.type() == typeid(int);          // true
a.type() == typeid(double);       // false

type() 返回 const std::type_info&。

any_cast 的四种形式

形式 返回 类型不匹配
any_cast<T>(a) T 抛 bad_any_cast
any_cast<T&>(a) T& 抛 bad_any_cast
any_cast<const T&>(a) const T& 抛 bad_any_cast
any_cast<T>(&a) T* 返回 nullptr 
std::any a = 42;

int x = std::any_cast<int>(a);              // OK
int& r = std::any_cast<int&>(a);            // OK
const int& cr = std::any_cast<const int&>(a); // OK
int* p = std::any_cast<int>(&a);            // OK，p 非空

// 类型不匹配
try {
    double d = std::any_cast<double>(a);    // 抛异常
} catch (const std::bad_any_cast& e) {
    std::cout << e.what();
}

double* q = std::any_cast<double>(&a);      // q == nullptr

any 的实现原理

核心思想：类型擦除

any 用类型擦除（type erasure）保存任意类型。核心是：

  • 一个指向存储的指针。
  • 一个虚函数表或函数指针，用于管理类型。

简化实现

class any {
    struct base {
        virtual ~base() = default;
        virtual std::type_info const& type() const = 0;
        virtual base* clone() const = 0;
    };

    template <typename T>
    struct holder : base {
        T value;
        holder(T v) : value(std::move(v)) {}
        std::type_info const& type() const override { return typeid(T); }
        base* clone() const override { return new holder(value); }
    };

    base* ptr_ = nullptr;

public:
    template <typename T>
    any(T v) : ptr_(new holder<T>(std::move(v))) {}

    ~any() { delete ptr_; }

    bool has_value() const { return ptr_ != nullptr; }
    std::type_info const& type() const { return ptr_ ? ptr_->type() : typeid(void); }
};

关键：

  • base 是抽象基类，定义接口。
  • holder<T> 是模板派生类，保存具体类型。
  • any 持有 base*，通过虚函数访问。

小对象优化（SOO）

标准库实现通常有小对象优化：小类型直接存在 any 内部，避免堆分配。

class any {
    union storage {
        void* ptr;         // 大对象：堆指针
        char buf[24];      // 小对象：内联存储
    };
    storage storage_;
    // 标记是内联还是堆
};

libstdc++ 和 libc++ 都有 SOO，通常能内联 2-3 个指针大小的对象。

any 的大小

sizeof(std::any);   // 通常是 16 或 32 字节，取决于实现

具体取决于：

  • 存储布局。
  • SOO 缓冲区大小。
  • 是否用虚函数表。

any 的实际用途

配置系统

class config {
    std::map<std::string, std::any> values_;
public:
    template <typename T>
    void set(const std::string& key, T value) {
        values_[key] = std::move(value);
    }

    template <typename T>
    T get(const std::string& key) const {
        return std::any_cast<T>(values_.at(key));
    }
};

config c;
c.set("port", 8080);
c.set("name", std::string("server"));
c.set("debug", true);

int port = c.get<int>("port");

any 的常见陷阱

性能开销

any 有：

  • 虚函数调用。
  • 可能的堆分配。
  • 类型检查。

所以不适合高频路径。如果需要高性能，用 variant 或模板。

类型必须完全匹配

std::any a = 42;              // int
std::any_cast<long>(a);       // 抛异常，int != long
std::any_cast<int>(a);        // OK

any 不做隐式转换。int 和 long 是不同类型。

const 和引用

std::any a = 42;
std::any_cast<const int&>(a);   // OK
std::any_cast<int&>(a);         // OK
std::any_cast<int&&>(a);        // 错误

any_cast 不支持右值引用。

数组和函数

std::any a = "hello";   // 存的是 const char*，不是数组

数组会退化为指针。

any 不支持 noexcept 移动

any 的移动构造可能抛异常（取决于实现）。这影响它在容器中的使用。

类型信息依赖 RTTI

any 用 typeid 做类型检查。如果禁用 RTTI，any 可能不可用或行为受限。

不支持 any 的 any

std::any a = std::any(42);   // 合法，但嵌套 any

嵌套 any 合法，但访问需要两次 any_cast。

没有 operator==

std::any a = 42, b = 42;
a == b;   // 编译错误，any 没有 ==

any 不支持比较。需要手动 any_cast 后比较。

any 的替代方案

方案 优点 缺点
void* 零开销 不安全，需手动管理
variant 类型安全，性能好 类型编译期固定
any 任意类型 性能开销，运行期检查
模板 零开销，类型安全 类型编译期固定
多态基类 类型安全 需要继承体系
std::function 类型擦除 只针对可调用对象

选择：

  • 类型编译期已知 → variant 或模板。
  • 类型运行期确定 → any。
  • 追求性能 → 避免 any。

any 的源码级细节

libstdc++ 的 any

class any {
    // 存储：小对象内联，大对象堆分配
    union _Storage {
        const void* _M_object;
        void (*_M_manager)(...);
        aligned_storage_t<...> _M_buffer;
    };
    _Storage _M_storage;
    const type_info* _M_type;
};

libc++ 的 any

class any {
    union __storage {
        void* __ptr;
        __dummy __buf[3];   // 小对象缓冲区
    };
    __storage __s_;
    const type_info* __t_;
};

两者都用：

  • 联合体存储。
  • 小对象优化。
  • type_info* 记录类型。

一句话总结

std::any 是 C++17 的类型擦除容器，能保存任意类型的单个值，并在运行期安全取回。 它用类型擦除实现，通常有小对象优化。访问用 any_cast，类型不匹配时抛异常或返回 nullptr。它适合类型在运行期确定的场景，但不适合高性能路径。在线性代数库里很少需要 any，因为矩阵类型通常在编译期确定。
