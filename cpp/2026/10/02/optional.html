std::optional 是 C++17 引入的可能无值的容器，定义在 <optional> 里。 它表示“要么有一个 T 类型的值，要么什么都没有”。它是 nullptr、特殊哨兵值、bool + T 组合的类型安全替代品。

是什么

std::optional<T> 是一个可能包含 T 类型值、也可能为空的容器。

一句话：optional 是“可能有值”的容器：它要么装一个 T，要么什么都不装。

std::optional<int> o1 = 42;        // 有值
std::optional<int> o2;             // 空
std::optional<int> o3 = std::nullopt;  // 空

为什么需要 optional

问题：函数可能返回“没有值”

假设一个函数查找整数，可能找到，也可能找不到。

方案 1：返回指针,问题：

  • 需要动态分配或返回内部指针。
  • 调用者需要判空。
  • 所有权不清晰。
int* find(const std::string& key);

方案 2：返回 bool + 输出参数,问题：

  • 调用者必须先构造 out。
  • 接口不直观。
bool find(const std::string& key, int& out);

方案 3：返回哨兵值, 问题：

  • -1 可能是合法值。
  • 哨兵值污染值域。 
    int find(const std::string& key);   // 返回 -1 表示找不到

方案 4：抛异常,问题：

  • 异常开销大。
  • “找不到”不是异常情况。
int find(const std::string& key);   // 找不到抛异常

optional 的解法

清晰、类型安全、零开销。

std::optional<int> find(const std::string& key);

auto result = find("foo");
if (result) {
    std::cout << *result;
} else {
    std::cout << "not found";
}

基本用法

定义与初始化

std::optional<int> o1;                    // 空
std::optional<int> o2 = 42;               // 有值 42
std::optional<int> o3 = std::nullopt;     // 空
std::optional<int> o4 = std::make_optional(42);  // 有值 42
std::optional<int> o5{42};                // 有值 42

检查是否有值

std::optional<int> o = 42;

if (o.has_value()) { /* 有值 */ }
if (o) { /* 有值，隐式转 bool */ }
if (!o) { /* 空 */ }

访问值

std::optional<int> o = 42;

int x = *o;          // 解引用
int y = o.value();   // 取值，空时抛 std::bad_optional_access

// 空时返回默认值
int z = o.value_or(0);   // 有值返回 42，空返回 0

修改值

std::optional<int> o;

o = 42;              // 赋值
o.emplace(100);      // 原地构造
o.reset();           // 清空

o = std::nullopt;    // 清空

比较

optional 支持所有比较运算符：

  • 两个 optional 比较：先比是否有值，再比值。
  • optional 与 T 比较：optional 有值时比值。
  • optional 与 nullopt 比较：判断是否为空。
std::optional<int> a = 42;
std::optional<int> b = 42;
std::optional<int> c = 100;
std::optional<int> d;         // 空

a == b;   // true
a == c;   // false
a == d;   // false
d == std::nullopt;  // true

排序规则：

  • nullopt < 任何有值的 optional。
std::optional<int> a;         // 空
std::optional<int> b = 0;     // 有值
a < b;   // true，空小于有值

optional 的实现原理

存储

optional 内部通常是一个联合体 + bool 标志：

template <typename T>
class optional {
    union storage {
        char empty;
        T value;
        storage() : empty() {}
        ~storage() {}
    } storage_;
    bool has_value_;
};
  • storage 是联合体，要么是空的 char，要么是 T。
  • has_value_ 记录当前是否有值。
  • 构造函数根据是否有值，决定是否 placement new 构造 T。
  • 析构函数根据 has_value_，决定是否调用 T 的析构。

大小

sizeof(std::optional<int>);      // 通常是 8
sizeof(std::optional<double>);   // 通常是 16
sizeof(std::optional<char>);     // 通常是 2

一般等于：

sizeof(T) + 对齐填充 + 1（bool）+ 对齐填充

零开销

如果 T 有一个“不可能的值”可以表示空，optional<T> 可以做到零开销。但标准库的 optional 不保证这一点，通常多一个 bool。

optional<T&> 不合法

std::optional<int&> o;   // 编译错误

optional 不能存引用。如果需要“可能无值的引用”，用 T* 或 std::reference_wrapper<T>。

std::optional<std::reference_wrapper<int>> o;

value_or 的细节

std::optional<int> o1 = 42;
std::optional<int> o2;

o1.value_or(0);   // 42
o2.value_or(0);   // 0

value_or 的返回类型是 T，不是 T&。所以：

std::optional<std::string> o = "hello";
o.value_or("default");   // 返回 std::string，不是引用

如果 T 是移动-only 类型：

std::optional<std::unique_ptr<int>> o;
auto p = o.value_or(nullptr);   // OK，移动

optional 的实际用途

函数返回可能无值

std::optional<int> parse_int(const std::string& s) {
    try {
        return std::stoi(s);
    } catch (...) {
        return std::nullopt;
    }
}

配置项

class config {
    std::optional<int> port_;
    std::optional<std::string> host_;
public:
    void set_port(int p) { port_ = p; }
    std::optional<int> port() const { return port_; }
};

缓存

class cache {
    std::optional<value_t> cached_;
public:
    const value_t& get() {
        if (!cached_) {
            cached_ = compute();
        }
        return *cached_;
    }
};

延迟初始化

std::optional<heavy_object> obj;
// 需要时再初始化
obj.emplace(args...);

成员可能不存在

struct person {
    std::string name;
    std::optional<std::string> nickname;
};

可选参数

void connect(const std::string& host, std::optional<int> port = std::nullopt);

可能有一个值，可能没有 optional<T>

optional 的常见陷阱

optional<bool>

std::optional<bool> o;
// o 有三个状态：空、false、true

容易混淆：

if (o) { /* 有值，但是 false 还是 true？ */ }
if (*o) { /* 值是 true */ }
if (o.value_or(false)) { /* 值是 true */ }

推荐用 optional<bool> 表示三态，但要注意区分“有值”和“值为真”。

optional<T> 和 T 的隐式转换

std::optional<int> o = 42;
int x = o;   // 错误：不能隐式转换
int y = *o;  // OK

optional 不隐式转换成 T，必须显式解引用。

value() 抛异常

std::optional<int> o;
int x = o.value();   // 抛 std::bad_optional_access

用 value_or 或先检查。

optional<T&> 不合法

std::optional<int&> o;   // 编译错误

用 T* 或 reference_wrapper。

嵌套 optional

std::optional<std::optional<int>> o;

合法，但访问需要两层：

if (o && *o) {
    int x = **o;
}

比较的陷阱

std::optional<int> a;         // 空
std::optional<int> b = 0;     // 有值

a < b;    // true，空小于有值
a == b;   // false
a == std::nullopt;  // true

空 optional 和 nullopt 相等，但不等于有值的 optional。

optional 的拷贝开销

std::optional<std::string> o = "hello";
auto copy = o;   // 拷贝整个字符串

optional 的拷贝会拷贝 T，可能开销大。

emplace 的参数

std::optional<std::vector<int>> o;
o.emplace({1, 2, 3});   // 错误：initializer_list 推导问题
o.emplace<std::initializer_list<int>>({1, 2, 3});  // 不推荐
o = std::vector<int>{1, 2, 3};  // OK

optional 和 constexpr

constexpr std::optional<int> o = 42;
static_assert(*o == 42);   // OK

optional 在 C++17 里不是完全 constexpr，C++20 改进了一些。

optional 的源码级细节

libstdc++ 的实现

template <typename T>
class optional {
    using _Stored_type = remove_cv_t<T>;

    struct _Empty_byte { };

    union _Storage {
        constexpr _Storage() : _M_empty() {}
        _Empty_byte _M_empty;
        _Stored_type _M_value;
    };

    _Storage _M_storage;
    bool _M_engaged = false;
};

libc++ 的实现

template <class T>
class optional {
    union __storage {
        char __empty_;
        T __value_;
    };
    __storage __s_;
    bool __engaged_;
};

两者都用：

  • 联合体存储（空字节或值）。
  • bool 标记是否有值。

一句话总结

std::optional<T> 是 C++17 的“可能无值”容器，同一时刻要么装一个 T，要么为空。 它用联合体 + bool 实现，零堆分配，类型安全。用 has_value、value、value_or、* 访问。 它替代了指针、哨兵值、bool + 输出参数，适合表示“可能没有结果”。
