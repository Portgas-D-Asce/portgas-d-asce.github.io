std::variant 是 C++17 引入的类型安全的联合体，定义在 <variant> 里。它能在同一块存储中保存多种类型之一，并且知道当前是哪一个。它是 union 的现代化替代品。

是什么

std::variant<Ts...> 是一个类型安全的联合体：任意时刻只保存 Ts... 中的一个值。

一句话： variant 是“多选一”的容器：它可能装 T1，可能装 T2，可能装 T3……但同一时刻只能装一个。

std::variant<int, double, std::string> v;
v = 42;              // 现在装 int
v = 3.14;            // 现在装 double
v = "hello";         // 现在装 std::string

为什么需要 variant

问题：union 不安全

union U {
    int i;
    double d;
    std::string s;   // 错误：非平凡类型不能在 union 里
};

union 的问题：

  1. 不知道当前存的是哪个成员，需要手动加标签。
  2. 不能放非平凡类型（有构造/析构函数的类型）。
  3. 不管理生命周期，需要手动调用构造/析构。
  4. 没有类型安全，读错成员是未定义行为。

variant 的解法

std::variant<int, double, std::string> v;
v = "hello";
std::cout << std::get<std::string>(v);   // 类型安全，知道当前是 string

variant 自动管理：

  • 当前是哪个类型（标签）。
  • 生命周期（构造/析构）。
  • 类型安全访问（get 检查类型）。
  • 异常安全（如果切换类型时抛异常）。

基本用法

定义：v 可以存 int、double、std::string 三者之一。

std::variant<int, double, std::string> v;

默认构造： 第一个备选类型必须可默认构造，否则 variant 不能默认构造。

std::variant<int, double, std::string> v;   // 默认是第一个类型 int，值为 0

赋值时，variant 会：

  1. 销毁当前值。
  2. 构造新值。
  3. 更新类型标签。
v = 42;              // 存 int
v = 3.14;            // 存 double
v = "hello";         // 存 std::string
v = std::string("world");  // 存 std::string

访问：std::get

v = 42;
int x = std::get<int>(v);          // OK
// double d = std::get<double>(v); // 抛 std::bad_variant_access

v = 3.14;
double d = std::get<double>(v);    // OK

按索引访问：

v = 42;
int x = std::get<0>(v);   // 第 0 个类型 int

检查当前类型

v = 42;
std::holds_alternative<int>(v);     // true
std::holds_alternative<double>(v);  // false

获取类型索引：index() 返回当前激活类型的下标。如果 variant 是 valueless_by_exception，返回 variant_npos。

v = 42;
v.index();   // 0，第一个类型

安全访问：std::get_if 返回指针，类型不匹配时返回 nullptr，不抛异常。

if (auto p = std::get_if<int>(&v)) {
    std::cout << *p;   // v 是 int
} else {
    std::cout << "not int";
}

visit：访问 variant 的标准方式

std::visit 是访问 variant 的推荐方式，它对当前类型调用一个可调用对象。visit 会根据 v 的当前类型，调用 lambda 的对应重载。

std::variant<int, double, std::string> v = 42;

std::visit([](auto&& x) {
    std::cout << x << "\n";
}, v);

更复杂的例子

struct printer {
    void operator()(int x) const { std::cout << "int: " << x << "\n"; }
    void operator()(double x) const { std::cout << "double: " << x << "\n"; }
    void operator()(const std::string& s) const { std::cout << "string: " << s << "\n"; }
};

std::visit(printer{}, v);

visit + if constexpr

std::visit([](auto&& x) {
    using T = std::decay_t<decltype(x)>;
    if constexpr (std::is_same_v<T, int>) {
        std::cout << "int\n";
    } else if constexpr (std::is_same_v<T, double>) {
        std::cout << "double\n";
    } else {
        std::cout << "other\n";
    }
}, v);

visit + overloaded 这是 C++17 的惯用法，用继承合并多个 lambda。

template <typename... Fs>
struct overloaded : Fs... {
    using Fs::operator()...;
};

template <typename... Fs>
overloaded(Fs...) -> overloaded<Fs...>;

std::visit(overloaded{
    [](int x) { std::cout << "int: " << x << "\n"; },
    [](double x) { std::cout << "double: " << x << "\n"; },
    [](const std::string& s) { std::cout << "string: " << s << "\n"; }
}, v);

monostate：让 variant 可默认构造

std::variant 要求第一个备选类型可默认构造。如果所有类型都不可默认构造：

struct NoDefault {
    NoDefault() = delete;
    NoDefault(int) {}
};

std::variant<NoDefault, std::string> v;   // 错误

用 std::monostate 作为第一个备选：monostate 是一个空类型，表示“空状态”。

std::variant<std::monostate, NoDefault, std::string> v;   // OK

variant 的实现原理

存储

variant 内部通常是：

  • union 保存所有类型的存储。
  • index_ 记录当前是哪个类型。
  • 用对齐确保 union 能容纳所有类型。
  • 用大小取所有类型的最大者。
template <typename... Ts>
class variant {
    union storage {
        T1 t1;
        T2 t2;
        // ...
    } storage_;
    size_t index_;   // 当前激活类型
};

生命周期管理

  • 构造：在 union 上 placement new。
  • 析构：调用当前类型的析构函数。
  • 赋值：先析构旧值，再构造新值。

异常安全,如果切换类型时新值构造抛异常：

  • 旧值已经析构。
  • 新值没构造成功。
  • variant 进入 valueless_by_exception 状态。
if (v.valueless_by_exception()) {
    // v 没有值
}

这是 variant 最尴尬的状态。index() 返回 variant_npos。

valueless_by_exception

只有在以下情况才会出现：

  1. 切换类型时，旧类型析构成功。
  2. 新类型构造抛异常。
  3. 且新类型不是 nothrow 构造。

现代实现尽量避免这个状态。

variant vs union vs any

  union variant any
类型安全 ❌ ✅ ✅
类型数量 编译期固定 编译期固定 运行期任意
知道当前类型 ❌ ✅ ✅
非平凡类型 ❌ ✅ ✅
生命周期管理 手动 自动 自动
头文件 语言 <variant> <any>
用途 底层 多选一 任意类型
  • union：C 风格，不安全。
  • variant：C++17，类型安全的联合体。
  • any：C++17，可以装任意类型，但访问需要知道类型。

variant 的常用操作

操作 作用
v = x 赋值，切换类型
v.index() 当前类型索引
v.valueless_by_exception() 是否无值
std::get<T>(v) 按类型访问，不匹配抛异常
std::get<I>(v) 按索引访问
std::get_if<T>(&v) 按类型访问，不匹配返回 nullptr
std::holds_alternative<T>(v) 检查当前类型
std::visit(f, v) 对当前类型调用 f
std::variant_size_v<V> 备选类型数量
std::variant_alternative_t<I, V> 第 I 个备选类型

variant 的实际用途

表示多态值

using Value = std::variant<int, double, std::string>;
std::vector<Value> values = {42, 3.14, "hello"};

解析结果

using ParseResult = std::variant<Success, Error>;
ParseResult parse(const std::string& s);

状态机

using State = std::variant<Idle, Running, Stopped>;

JSON 值

using Json = std::variant<
    std::nullptr_t,
    bool,
    double,
    std::string,
    std::vector<Json>,
    std::map<std::string, Json>
>;

错误处理

std::variant<T, std::error_code> result;

variant 的常见陷阱

默认构造要求

std::variant<NoDefault, int> v;   // 错误：NoDefault 不可默认构造

用 monostate 解决。

重复类型

std::variant<int, int> v;   // 合法，但 get<int> 有歧义

std::get<int>(v) 编译错误，因为 int 出现两次。用索引访问：

std::get<0>(v);
std::get<1>(v);

valueless_by_exception

std::variant<int, Thrower> v;
try {
    v = Thrower{};   // 构造抛异常
} catch (...) {
    // v 可能 valueless
}

get 抛异常

std::variant<int, double> v = 42;
std::get<double>(v);   // 抛 std::bad_variant_access

用 get_if 避免异常。

引用类型

std::variant<int&, double&> v;   // 合法，但要小心生命周期

visit 返回值

auto result = std::visit([](auto&& x) { return x; }, v);

所有分支的返回类型必须一致，或者能推导出公共类型。

visit 多参数

std::visit(f, v1, v2);   // f 必须能处理所有类型组合

v1 有 N 种类型，v2 有 M 种类型，f 必须能处理 N×M 种组合。

一句话总结

std::variant<Ts...> 是 C++17 的类型安全联合体，同一时刻只保存 Ts... 中的一个值。它自动管理生命周期和类型标签，用 get、get_if、visit 访问。monostate 用于让 variant 可默认构造。它是 union 的现代替代品，用于表示“多选一”的类型。
